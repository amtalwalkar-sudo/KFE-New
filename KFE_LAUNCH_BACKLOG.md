# KFE Deferred Scope Register

**Status:** Scope guard only; not an active feature roadmap.
**Authority:** `KFE_BUSINESS_RULES_REGISTER.md`.

No feature in this file is approved for implementation merely by appearing here. The current product is limited to Work/ride workflow, Timeline, basic recorded-data Performance, basic Admin forms/data, Capacitor-native Android overlay/GPS, and essential backup/recovery.

## Explicitly out of scope unless requested

- Targets, forecasts, break-even, provisions, profitability projections and loan amortization.
- Ride-distance calculations, route tracing, continuous GPS tracking and automatic locality resolution.
- OCR/multimodal ride import or synthetic business data.
- Separate notification products or alternate shells/workflows.
- New accounting, ledger, settlement, prepayment or finance dashboards.

Historical data may remain in compatibility/recovery stores where required for backup/restore. Its presence does not reactivate the retired workflow or calculation.

## Change rule

A capability can enter scope only after explicit user approval and an update to the business-rule register, affected architecture/data contracts, tests, and implementation plan.
